# 2.9.2 — 2026-08-21

## Changed

- **`@cyanheads/mcp-ts-core` `^0.11.5` → `^0.12.3`** — the MCP SDK v2 migration; the runtime package split out `@modelcontextprotocol/server`, and the packaging linter's critical-path check follows.
- **`find_eligible`'s `location` and `get_study_record`'s `nearLocation` now reject an undeclared key by name** instead of silently stripping it — a typo'd `zipCode` previously widened the match to the whole country, and a typo'd `radiusKm` silently fell back to the 50-mile default.
- **`MCP_SESSION_MODE` defaults to `auto`** (resolves to `stateful`); added `MCP_HTTP_RESUMABILITY` (+ `_MAX_EVENTS`/`_TTL_MS`) for replaying a dropped SSE stream on `Last-Event-ID`.
- **Docker build stage pinned to `--platform=$BUILDPLATFORM`, bun `1.3.14` → `1.4.0`** — under QEMU emulation Bun's JavaScriptCore aborts with a spurious `MemoryExhaustion` assertion, so the build stage (platform-independent JS output, no reason to emulate) now always builds natively.

## Removed

- **Dropped `devdocs`, `docs:generate`, `lint`, `lint:fix`, `fetch-spec`, `coverage:update`, `coverage:commit` scripts and the `typedoc` devDependency** — clears the last `bun audit` advisories (0 vulnerabilities across 375 packages).
