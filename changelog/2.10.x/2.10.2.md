# 2.10.2 — 2026-10-25

## Added

- **Agent Plugins root manifest**: root `plugin.json` and `mcp.json` (Agent Plugins 1.0.0) describe the stdio server launched with `npx -y clinicaltrialsgov-mcp-server` (mcp-ts-core 0.13.18 template).

## Changed

- **Error text in `content[]` is Markdown-escaped** (mcp-ts-core 0.13.16): the `Error:` message, `Recovery:` hint, and reason of a failed tool call backslash-escape the characters CommonMark would act on (backticks, `[`, `]`, `|`), so a Markdown-rendering client shows them as written. `structuredContent.error` is unchanged; the `enum_invalid` hint `fields=["OverallStatus"]` now arrives in `content[]` text as `fields=\["OverallStatus"\]`.
- **An out-of-range framework config value fails startup** (mcp-ts-core 0.13.16): framework count and timer variables must be integers in range, so `MCP_HTTP_PORT=3977.5` stops startup with a configuration banner naming `MCP_HTTP_PORT`, where 2.10.1 started. `CT_*` validation is unchanged.
- **`.mcpb` bundle contents** (mcp-ts-core 0.13.18): `.mcpbignore` is root-anchored and also leaves out `docs/`, `changelog/`, `coverage/`, the plugin manifests, `CLAUDE.md`/`AGENTS.md`, repo config files, and the legacy `changelogs/` archive; `clean-mcpb` strips the framework's build-only files (its `changelog/`, `scripts/`, `templates/`, `CLAUDE.md`) and node-gyp build output.
- Framework skills, scripts, Dockerfile, and the bug-report form synced to mcp-ts-core 0.13.18; `bunfig.toml` release-age guard 3 days → 1 day.
