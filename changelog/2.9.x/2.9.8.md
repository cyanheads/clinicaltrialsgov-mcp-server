# 2.9.8 — 2026-09-18

## Added

- **Declared stateless session mode** (mcp-ts-core 0.13.1, [#115](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/115)) — `src/index.ts` now declares `sessionMode: 'stateless'` in `createApp`. HTTP run from source, `bunx`, or `npm start` are now stateless, as the Docker image already was, and no `Mcp-Session-Id` is issued. An explicit `MCP_SESSION_MODE` still overrides the declared default. `.env.example` sets `MCP_SESSION_MODE=stateless` actively (previously a commented-out example), and the README configuration table gained an `MCP_SESSION_MODE` row.

## Changed

- **Argument rejections carry a recovery hint** (mcp-ts-core 0.13.3) — the error text now ends with a `Recovery: …` line and `data.reason` is `"invalid_arguments"`; a missing required field reads as missing.
- **Undeclared root keys are dropped instead of rejected** (mcp-ts-core 0.13.4) — a client-added key at the input root no longer fails the call. Same release adds case-style key aliasing and repair of a JSON-stringified array input.
- **Upstream error URLs no longer echoed** (mcp-ts-core 0.13.4) — a ClinicalTrials.gov HTTP error no longer carries the request URL in `error.data.url`.
- Framework skills, devcheck/build/lint scripts, and the CodeQL workflow template synced from mcp-ts-core 0.13.4; `package.json`'s npm `files` allowlist now also ships `changelog/`, `README.md`, `LICENSE`, `CLAUDE.md`, `AGENTS.md`, `Dockerfile`, and `server.json`; `.codex-plugin/plugin.json` gains a `Research` category.
