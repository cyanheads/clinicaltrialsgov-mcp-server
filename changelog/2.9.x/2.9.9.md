# 2.9.9 — 2026-09-22

## Added

- **`search_studies` compact index gains `hasResults`, `startDate`, `primaryCompletionDate`** ([#139](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/139)) — the default per-study projection and `format()` meta line now carry these three fields when the study publishes them; explicit `fields` projections are unchanged. `advancedFilter` gains a documented `AREA[HasResults]true` example.

## Changed

- **`statusFilter` accepts case and spacing variants** ([#140](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/140)) — upstream matches `filter.overallStatus` case-sensitively; `search_studies`, `get_study_count`, and `get_field_values` now normalize each entry (trim, uppercase, collapse whitespace/hyphen/underscore runs) before the request, including the registry display labels `"Active, not recruiting"` and `"Unknown status"`. A value that still names no status still reaches upstream and fails as `enum_invalid`.
- **NCT IDs accept case and whitespace variants** ([#140](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/140)) — the shared `nctIdSchema` trims and uppercases before the format check, so `nct03722472` resolves the same as `NCT03722472` across every tool and the `clinicaltrials://{nctId}` resource; the advertised JSON Schema `pattern` is unchanged.
