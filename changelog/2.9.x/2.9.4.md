# 2.9.4 — 2026-09-12

## Added

- **`outcomeOffset` / `seriousEventOffset` / `otherEventOffset` resume a capped `clinicaltrials_get_study_results` list** ([#124](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/124)) — the two adverse-event lists page on independent axes, per-study `filtersApplied` names the next offset for every list left short, and a new `offset_not_applicable` error answers an offset supplied in summary mode or against a section `sections` excludes.

## Fixed

- **`clinicaltrials_get_study_results` no longer infers "not reached" from an `NA`/`NR` `MEDIAN` measurement** ([#116](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/116)) — the raw sentinel and the record's own `comment` now reach both channels verbatim instead of a blanket, often-wrong label.
- **Summary-mode `topStats` no longer detaches a value from what it measures** ([#126](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/126)) — `topStatsFrom` names the class and category the projected cell came from and counts the siblings it displaced, each retained cell keeps its `spread` and `lowerLimit`/`upperLimit`, and the measure carries its per-group `denoms` and `dispersionType`.
- **Rendered measurement, denominator, participant-flow, and adverse-event cells are keyed by group ID instead of a truncated title** ([#128](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/128)) — two arms whose titles collided past the old 40-character cut are now distinguishable in `content[]`, and the untruncated `id: title` roster still prints once per section.
- **A previous (alias) NCT ID no longer returns a false "Study not found"** ([#127](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/127)) — `getStudiesBatch` now requests `NCTIdAlias`, and a resolved alias is answered under its canonical study with `canonicalNctId` naming it.

## Changed

- Duplicate requested `nctIds` collapse to one results entry, in first-occurrence order ([#124](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/124)) — the same ID named twice describes one study, and answering it twice spent the caller's payload on a byte-identical copy.
- Docs describe full-mode results as exceeding 500KB per study rather than ~200KB, and record the gated release PR mode.
