# 2.10.0 — 2026-10-14

## Changed

- **BREAKING: `phaseFilter` entries that name no phase fail as `enum_invalid` in the handler** (#144). `(PHASE3)`, `(PHASE2 OR PHASE3)`, `Phase3*`, and `PHASE3 AND PHASE3` returned counts in 2.9.11 and are now rejected; put expressions in `advancedFilter`. Case, spacing, `-`, `_`, quotes, and `,`/`|` joins resolve to canonical values (`"Phase 3"` → `PHASE3`, `"PHASE2,PHASE3"` → `[PHASE2, PHASE3]`), on `search_studies` and `get_study_count`. `searchCriteria.phaseFilter` echoes the canonical values sent, and an invalid value inside an `AREA[Phase]` expression in `advancedFilter` is reported against that expression, no longer as `phaseFilter`.
- **BREAKING: `find_eligible` rejects values made only of `"`, whitespace, and zero-width characters as `blank_value`** (#145). `conditions: ["Diabetes", "\" \""]` returned results in 2.9.11. An optional `city` or `state` with no content is treated as unset.
- **`clinicaltrials_find_eligible` returns candidates, not eligible studies** (#147). The description, output labels (`Demographic criteria`), and package metadata say so, and every non-empty response carries a `notice` that inclusion/exclusion criteria were not checked.
- **`get_study_results` summary mode honors `outcomeLimit` / `outcomeOffset`** (#149). It was previously a no-op with `summary: true`; the windowed list carries the same `truncated` roll-up and `Bounded:` line as full mode. In both modes the `Bounded:` line now counts the rows each window returned (`61 of 71 outcome measures (from outcomeOffset 10)`) and names only the bounds that trimmed a list on that study.
- **`get_study_results` summaries stay attributable** (#146). `topStatsFrom.classDenoms` carries the shown class's own denominators, each measure reports `analysisCount`, and `topAnalysis` adds `groups` (compared group titles) with `groupDescription` kept verbatim.
- **`get_study_results` accepts `nctId` as an alias of `nctIds`** (#151). Sending both is rejected.
- **`.mcpbignore`** excludes `tests/`, `src/`, `scripts/`, `.husky/`, `.github/`, `.vscode/`, and `.codex/`.
- Framework skills, `scripts/check-framework-antipatterns.ts`, `.env.example` (`MCP_REQUEST_STATE_KEY`, `LOG_LLM_INTERACTIONS`), CLAUDE.md, AGENTS.md, and the README and design doc updated to match.

## Added

- **`page_token_invalid`** (#148). `search_studies` fails a pageToken ClinicalTrials.gov rejects (malformed, issued before a data refresh, or altered) with this typed, non-retryable reason and a restart hint.
- **`fields` splits comma- and pipe-joined names** (#152). `["NCTId,BriefTitle"]` becomes two names with repeats dropped, on `search_studies` and `get_field_values`.

## Fixed

- **`get_study_results` `nctIds` is advertised in the input schema's `required`** (#154); the shared NCT ID schema no longer uses `z.preprocess`.
- **`find_eligible` quoted `city`, `state`, and `country` score their own sites** (#155), and condition re-ranking uses the quote-stripped query.
- **`get_study_results` flattens line breaks** in analysis comments and class, category, and group titles on `content[]` (#156), and in its other single-line rows: outcome, adverse-event, participant-flow, baseline, and more-info rows and the study heading. `structuredContent` keeps the originals.
