# 2.8.5 — 2026-07-26

## Fixed

- **`clinicaltrials_get_study_record` `format()` dropped many `structuredContent` leaves** — including the entire observational-study subtree (`observationalModel`, `timePerspective`, `samplingMethod`, `studyPopulation`, `bioSpec`, `patientRegistry`) that interventional studies never populate. Now also renders date-struct ACTUAL/ESTIMATED qualifiers, outcome descriptions, ID provenance on org/secondary study IDs, masking detail, per-site contacts, overall officials, responsible party, expanded-access info, document metadata, reference retractions, and the rare annotation/violation and submission-tracking sections. ([#18](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/18))
- **`clinicaltrials_get_study_results` full mode sampled only the first class and category of each measure** — `extractTopStats`, built for summary mode's condensed `topStats`, was also the fallback full-mode used, so a measure with multiple classes or timepoints rendered only the first. Full mode now walks the complete classes → categories → measurements tree via a dedicated renderer, plus every analysis field and event/group/period detail across all four result sections; summary mode gained `reportingStatus`, `classCount`, and description/population text it was missing. ([#63](https://github.com/cyanheads/clinicaltrialsgov-mcp-server/issues/63))
